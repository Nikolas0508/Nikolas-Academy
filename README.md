# Nikolas Academy

Ferramenta desenvolvida para uso na plataforma Khan Academy, com o objetivo de otimizar a navegação e melhorar a experiência do usuário durante o uso da plataforma.

## 📌 Sobre

O Nikolas Academy é um bookmarklet executado diretamente pela barra de favoritos do navegador. Ele permite aplicar funcionalidades extras na interface da Khan Academy de forma rápida e prática.

## ⚙️ Como usar

1. Adicione o script como favorito (bookmarklet) no seu navegador
2. Acesse a plataforma Khan Academy
3. Clique no bookmarklet salvo na barra de favoritos
4. As funcionalidades serão aplicadas automaticamente na página

## 🚀 Funcionalidades

* Melhorias na interface
* Automatização de ações repetitivas
* Otimização da navegação

## 🧩 Tecnologias

* JavaScript (executado via bookmarklet)
* DOM manipulation

## ⚠️ Aviso

Este projeto não é afiliado oficialmente à Khan Academy.
